# TROA Profiler+ Changelog

## v1.0.0-alpha.1

- New headless Torch profiler built from the ground up.
- Rolling simulation, process, entity, grid, and block metrics.
- Health scoring, top-grid pressure, incident confirmation, and cooldowns.
- CSV history, JSON latest snapshot, manual exports, and local diagnostics.
- Optional Discord incident embeds.
- Moderator diagnostics and administrator lifecycle/configuration commands.
- Windows and Linux-hosted AMP/Wine path compatibility.
