## Changes

- Moves baseline and detached sampled-data analysis out of the blocking game-thread callback for regular timer captures.
- Caps low-speed detailed inspection at 10 grids per 60 seconds by default; inventory sampling continues and cached details may be older.
- Prunes removed-grid detail cache entries and excludes unloaded-world snapshots from incident evaluation.
- Coordinates with local Cleaner+ v1.12.0 recovery work; no automatic grid mutation added to Profiler+.
- Local ZIP under releases/; live testing remains with the owner.

## Installation and operation

Replace the installed plugin ZIP using the normal stopped-server procedure. Preserve your existing private configuration and webhook credentials. Existing saved settings are retained; use the example inside this package for the candidate's configuration options. Builds alone do not establish live server stability.

Low-speed detailed inspection defaults to 10 grids per 60 seconds (`MaximumDetailedGridsWhileLow`, `LowSimulationDetailedAnalysisSeconds`). Regular inventory sampling continues; cached details can be older. Existing recovery configurations keep their values; set `SimulationRecoverySamples` to 1 if one healthy confirmation is wanted. Profiler+ reports performance and does not remove game workload.
